[tradingview/lightweight-charts](https://github.com/tradingview/lightweight-charts/tree/master/.github/skills)

the Apache License 2.0 (the same licence as this project and as the bundled library). Claude Code loads skills in
`.claude/skills/` when it works in this repository.

To update them, copy the folders again from the upstream repository and change the commit above.
