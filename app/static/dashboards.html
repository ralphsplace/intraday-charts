Create a dashboard

A dashboard keeps its window (charts, studies, sizes) in each browser. "Start from" sets what a browser sees the first time it opens it. Duplicate copies a dashboard's settings, and in this browser its window too.

Environment check

The dashboard has no logins: only devices on your home network can use it, and it only reads from TWS. These checks run when the server starts; a failed one stops it.
