Create a dashboard

A dashboard keeps its window (charts, studies, sizes) in each browser. "Start from" sets what a browser sees the first time it opens it. Duplicate copies a dashboard's settings, and in this browser its window too.

Environment check

The dashboard has no logins: only devices on your home network can use it, and it only reads from TWS. These checks run when the server starts; a failed one stops it.

Charts drawn with TradingView Lightweight Charts (Apache 2.0).

Watch lists

Every named watch list, as the watch list panels and Load data show them. Names are unique; renaming keeps the list (every tab showing it follows), deleting removes it everywhere.

Watch list columns

The columns a new tab starts with, and their order, for each type of watch list. A tab can still choose its own (Columns in the watch list).

    Study defaults

    The settings and colours a study starts with when it's added to a chart, and what its Defaults button puts back. Studies already on charts keep their own settings.

      Paper accounts

      Accounts for practising in Replay and for backtests. They're simulated on the NAS from the cached bars and never talk to TWS or your IBKR account. Names are unique; renaming keeps the history; a reset puts the balance back to the starting cash and keeps the history.

      Settings

      Paper rules

      When to enter and leave a trade, built from prices and study lines, read at each bar's close. A study whose past values change as new bars arrive is refused, as a rule would otherwise look ahead. Rules are run on the Paper trading page (Backtests).

      Backtests

      What the Run form on the Paper trading page starts with. Each run can still change them.

      Random runs: how many times the same exits are tried on random entries, as the baseline the rule is measured against (0 for none). Without "Skip", a day without cached bars stops the run.
